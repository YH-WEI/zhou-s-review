Read, in order:

1. `energy_digital_coordination_review_detailed_framework.md`
2. `review_evidence_map/00_SCOPE_AND_NONCLAIMS.md`
3. `review_evidence_map/01_SOURCES_AND_SEARCH.md`

6. `review_evidence_map/04_CODEX_EXECUTION.md`
7. `review_evidence_map/config/search_plan.yml`

Then execute every required phase and acceptance check in `04_CODEX_EXECUTION.md`.

## Hard boundary

This task is a reproducible literature evidence map. Do not add a new joint scheduling model, power-system simulation, AI controller, meta-analysis or “1+1>2” proof. Do not modify the existing source Word/PDF files.

## Delivery

Create branch `codex/review-evidence-map-results`, commit code/data/results/audits, and open an unmerged pull request to `main`. `review_evidence_map/results/REVIEW_HANDOFF.md` is the required handoff entry point.
