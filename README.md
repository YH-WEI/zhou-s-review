# zhou-s-review

This repository contains the source materials and the reproducible evidence-mapping work for the Review:

> **Energy–digital coordination of data centres, next-generation base stations, electric vehicles and smart buildings for multi-asset grid services**

## Start here

1. [`energy_digital_coordination_review_detailed_framework.md`](energy_digital_coordination_review_detailed_framework.md) — fixed article framework, terminology, chapter duties, figures/tables and anti-drift rules.
2. [`review_evidence_map/README.md`](review_evidence_map/README.md) — the execution contract for Codex.
3. [`review_evidence_map/01_SOURCES_AND_SEARCH.md`](review_evidence_map/01_SOURCES_AND_SEARCH.md) — where the literature and metadata come from, and how they must be logged.
4. [`review_evidence_map/02_EVIDENCE_CODEBOOK.md`](review_evidence_map/02_EVIDENCE_CODEBOOK.md) — the machine-checkable extraction schema.
5. [`review_evidence_map/03_ANALYSIS_SPEC.md`](review_evidence_map/03_ANALYSIS_SPEC.md) — the permitted calculations and required outputs.
6. [`review_evidence_map/04_CODEX_EXECUTION.md`](review_evidence_map/04_CODEX_EXECUTION.md) — phase-by-phase implementation and acceptance checklist.

## Source hierarchy

- `周跃宽的idea.docx` is the formal source of the original idea.
- The detailed framework above is the fixed Review organization agreed after interpreting that idea.
- The files under `review_evidence_map/` specify the quantitative evidence map that supports the Review.
- Chinese translations and explanatory notes are aids to understanding; quantitative claims must trace back to the original paper, standard or official source.
- PDFs under `nature energy综述例子集合/` are style and organization exemplars unless they independently satisfy the topical inclusion rules. They are not automatically part of the evidence corpus.

Do not overwrite or rewrite the source Word/PDF files. New code, extracted data, logs, tables and figures belong under `review_evidence_map/`.
